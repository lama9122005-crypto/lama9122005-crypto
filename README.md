أنا مطورة واجهات أمامية أستمتع بتحويل التصاميم والأفكار إلى مواقع وتطبيقات ويب تفاعلية، سريعة الاستجابة، وجذابة بصرياً 🌐. أمتلك اهتماماً عالياً بأدق التفاصيل في التصميم وأسعى دائماً لكتابة كود نظيف (Clean Code) وتطوير حلول برمجية أنيقة وفعالة 🛠️.

<br/>

### 💫 لمحة عني:

- 🔭 &nbsp; **أعمل حالياً على:** تطوير تطبيقات ويب متكاملة وتفاعلية، مثل أنظمة إدارة المنتجات (CRUD Systems) باستخدام `localStorage`.
- 🌐 &nbsp; **أستمتع ببناء:** واجهات متجاوبة (Responsive) باستخدام CSS Flexbox، وتوظيف الـ Media Queries، والـ Pseudo-elements لإضافة لمسات بصرية مميزة.
- 🌱 &nbsp; **أتعلم وأتعمق حالياً في:** مفاهيم الـ JavaScript المتقدمة مثل Asynchronous, Promises، وتقنيات التعامل مع الـ DOM، ودمج الـ APIs الخارجية (مثل TVMaze و CoinGecko) باستخدام `Axios` و `Fetch`.
- 🤝 &nbsp; **أتطلع للتعاون في:** مشاريع Front-End مفتوحة المصدر وتطبيقات الويب التفاعلية.
- 💬 &nbsp; **اسألني عن:** HTML, CSS, JavaScript, وكيفية إدارة واجهات المستخدم بشكل ديناميكي.
- 📫 &nbsp; **للتواصل معي:** يمكنك مراسلتي مباشرة عبر [البريد الإلكتروني](mailto:lama9122005@gmail.com)
- ⚡ &nbsp; **حقيقة ممتعة:** البرمجة بالنسبة لي ليست مجرد كتابة أكواد، بل هي فن صناعة تجربة مستخدم لا تُنسى!
